description: Planeja uma feature backend antes de codar.
---

## Objetivo
Evitar começar sem arquitetura.

## Quando usar
- Antes de criar APIs
- Antes de mexer em banco
- Features médias/grandes

## Passos
1. Definir objetivo da feature
2. Listar endpoints necessários
3. Definir estrutura de dados
4. Planejar fluxo
5. Identificar riscos

## Output esperado
- Estrutura da feature
- Endpoints
- Modelos de dados

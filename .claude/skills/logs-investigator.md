## Objetivo
Encontrar erros que ninguém viu.

## Quando usar
- Bugs intermitentes
- Sistema em produção

## Passos
1. Filtrar logs relevantes
2. Identificar padrões de erro
3. Correlacionar eventos
4. Sugerir causa

## Output esperado
- Causa provável
- Evidências

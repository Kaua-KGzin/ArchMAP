---
name: optimize-code
description: Improves performance and efficiency of code. Use when code is slow, inefficient, or the user asks for optimization.
---

When optimizing code:

1. **Understand current behavior**: What the code does and constraints
2. **Identify bottlenecks**: Loops, redundant operations, memory usage
3. **Suggest improvements**:
   - Algorithm improvements
   - Data structure changes
   - Caching or memoization
4. **Compare before/after**: Explain performance gains
5. **Keep readability**: Don't sacrifice clarity for micro-optimizations

Always explain trade-offs.

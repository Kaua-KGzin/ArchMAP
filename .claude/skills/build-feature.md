## Objetivo
Transformar requisitos em código funcional, organizado e utilizável.

## Quando usar
- Criar nova feature
- Implementar endpoint ou lógica de negócio
- Construir módulo do zero

## Passos
1. Entender requisitos e entradas/saídas
2. Definir estrutura (funções, classes, rotas)
3. Implementar lógica principal
4. Tratar erros e edge cases
5. Adicionar exemplos de uso

## Regras
- Código deve ser modular
- Evitar duplicação
- Priorizar legibilidade

## Output esperado
- Código completo
- Explicação curta
- Exemplo de uso

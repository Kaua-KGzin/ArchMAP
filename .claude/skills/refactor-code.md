---
name: refactor-code
description: Improves code structure without changing behavior. Use when code is messy, duplicated, or hard to maintain.
---

When refactoring:

1. **Understand current behavior**
2. **Identify problems**:
   - Duplication
   - Long functions
   - Poor naming
3. **Apply improvements**:
   - Break into functions
   - Rename variables
   - Simplify logic
4. **Ensure same output**
5. **Explain improvements clearly**

Keep code cleaner, not just different.

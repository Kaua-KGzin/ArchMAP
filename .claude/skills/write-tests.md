description: Writes unit and integration tests. Use when testing code, ensuring reliability, or improving coverage.
---

When writing tests:

1. **Understand functionality**: What needs to be tested
2. **Cover key cases**:
   - Normal cases
   - Edge cases
   - Error cases
3. **Use clear structure**: Arrange, Act, Assert
4. **Keep tests readable**
5. **Avoid duplication**
6. **Explain what each test validates**

Focus on meaningful coverage, not just quantity.

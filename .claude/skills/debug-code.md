---
name: debug-code
description: Finds and fixes bugs in code with clear reasoning. Use when the user has errors, unexpected behavior, or asks "why is this not working?"
---

When debugging code, follow this process:

1. **Reproduce the issue**: Restate what the code is supposed to do vs what it's doing
2. **Scan for obvious issues**: Syntax errors, undefined variables, wrong logic
3. **Trace execution**: Step through the code mentally or with examples
4. **Identify root cause**: Don't just fix symptoms
5. **Provide fix**: Show corrected code and explain why it works
6. **Suggest prevention**: Tips to avoid similar bugs

Be precise, avoid guessing, and explain clearly.

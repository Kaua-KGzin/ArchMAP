# Contributing

## Quick checklist

1. Create a branch from `dev` (`feat/*`, `fix/*`, or `docs/*`).
2. Implement the change with tests.
3. Run:
   - `python -m ruff check .`
   - `python -m pytest -q`
4. Update changelog or docs for behavior changes.
5. Open the PR to `dev` (or `release/*` during stabilization).

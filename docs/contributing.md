# Contributing

## Quick checklist

1. Create branch from `dev` (`feat/*`, `fix/*`, or `docs/*`).
2. Implement change with tests.
3. Run:
   - `python -m ruff check .`
   - `python -m pytest -q`
4. Update changelog/docs for behavior changes.
5. Open PR to `dev` (or `release/*` during stabilization).
